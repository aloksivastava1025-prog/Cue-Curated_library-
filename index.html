What Cue is

Cue is an Awwwards-tier component library for anyone building to stand out — the best-in-class components from across the internet, curated by hand. Not just for AI builders: designers, developers, agencies, solo makers, and product teams who refuse to ship generic-looking work. Each entry is a component reference sourced from an Awwwards Site of the Day, a Behance-featured interaction, or a production output the founder considered best-of-class. Today Cue ships AI prompts for every component (drop into Bolt, v0, Cursor, Framer AI, ChatGPT, Claude); React source code and an MCP server (native access from Cursor / Claude Desktop / any MCP-aware AI tool) are actively rolling out. Cue does not host projects, deploy code, or run an AI model itself — it is the taste layer on top of the tools people already use.

What Cue is not

Not a template pack. Not a subscription. Not a course. Not an AI wrapper. Not a marketplace.

Plans

  • Free — browse the library, 2 AI-prompt copies per 24 hours.
  • Cue+ Founding Lifetime — USD $99 one-time, capped at the first 50 members.
  • Cue+ Lifetime (standard) — USD $249 one-time after founding sells out.

Differentiator

Every item is hand-picked from an Awwwards-tier website or a best-in-class interaction. Nothing is machine-generated to fill the grid. If a user finds a better reference for the same component, the founder replaces it — the bar is taste, not volume.
